# 作战室骨架开发说明

骨架已完成数据读取、球员卡片、雷达图和四个页面（老板首页、人才库、选人台、阵容报告）。
现场只需编写一个文件：`boss.js`。不要修改 `index.html` 和 `data.js`。

## boss.js 需要定义两样东西

### 1. window.BOSS：老板配置

```js
window.BOSS = {
  team: "球队中文名",
  style: "风格名称，如：明星型",
  quote: ["访谈原话 1", "访谈原话 2"],     // 顶栏显示全部原话；quote[1] 用于选人台超预算时的建议
  w: { score: .35, gravity: .3, create: .2, defense: .15 }, // 评分权重，合计为 1
  big: { "季后赛更强": 8, "季后赛下滑": -5 },               // 大场面加减分，可为空对象
  cap: 99,                                                 // 单人薪资上限：4-30，或 99 表示不设上限
  core: p => p.c >= 20 && p.big !== "未进季后赛",          // 可选：什么样的人能当核心
  exclude: p => p.pr.steady < 10                           // 可选：什么样的人一律不要
};
```

- 六个能力维度的键：`score` 得分、`create` 组织、`rebound` 篮板、`defense` 防守、`steady` 稳健（失误少）、`gravity` 牵制。取值均为联盟百分位 0-100。
- `big` 的可用键：`季后赛更强`、`季后赛下滑`、`季后赛稳定`、`未进季后赛`。
- `cap` 的取值：4-30，或 99 表示不设上限。99 时预算可集中给明星，14-20 时预算分散。总预算 100 点、阵容 8 人、最低薪资 4 点。
- `core`（可选）：返回 true 的球员才能当核心。推荐时先按评分选两名核心，再补齐阵容。不写则所有人都可当核心。老板对核心有硬性要求时（如「必须打过季后赛」「必须是公认球星」）用它。
- `exclude`（可选）：返回 true 的球员不进入推荐阵容，但仍在人才库中显示，老板可手动选入。
- 老板的硬性要求优先写进 `core` 和 `exclude`，不要只在首页加提示。

### 2. window.renderHome(ctx)：老板首页

返回首页的 HTML 字符串。`ctx` 提供：

| 字段 | 说明 |
|---|---|
| `ctx.roster` | 当前阵容（按评分从高到低），每人字段：`n` 中文名（卡片上无中文名时显示英文名）、`en` 英文名、`t` 球队、`age` 年龄、`yr` 本赛季是第几个 NBA 赛季（1 为新秀）、`fame` 知名度（`全明星` 为 2026 全明星赛出场，`得分前 20` 为场均得分前 20，其余为空）、`pts` `reb` `ast`、`c` 薪资、`o` 关键时刻影响力总分的联盟百分位（0-100），可作综合参考（可不使用）、`pr` 六维画像、`role` 角色、`big` 大场面标签、`img` 头像（本地相对路径 `headshots/<id>.png`，不联网也能显示）。`en` `age` `yr` `fame` `pts` `reb` `ast` `o` 为可选字段，可能为空，使用前先判断 |
| `ctx.core` | 核心球员：阵容中满足 `core` 条件、评分最高的两人，与推荐时选核心的口径相同（推荐阵容下就是推荐选出的两名核心）。`BOSS.core` 未设置或阵容中无人满足时为空数组，此时首页不要出现「核心」字样，改为显示评分最高的两人（`ctx.roster.slice(0, 2)`） |
| `ctx.profile` | 阵容六维平均值 |
| `ctx.spent` / `ctx.BUDGET` | 已用预算 / 总预算 |
| `ctx.DIMS` / `ctx.DIM_KEYS` | 维度中文名 / 维度键列表 |
| `ctx.LEAGUE` | 联盟平均（六维均为 50） |
| `ctx.score(p)` | 按老板权重计算的评分 |
| `ctx.reason(p)` | 球员的入选理由文字 |
| `ctx.radar(series, size)` | 雷达图 SVG，`series` 形如 `[{ v: ctx.profile, color: "#fbbf24" }]` |
| `ctx.playerCard(p, withReason)` | 球员卡片 HTML |
| `ctx.status()` | 预算和短板的一句话状态 |
| `ctx.gaps()` | 短板维度的中文名列表 |
| `ctx.count("big", "季后赛更强")` | 阵容中某个标签的人数 |

可用样式类：`card`、`grid`、`split`（左右两栏）、`verdict`（大号结论文字，`<b>` 为高亮色）、`warn`、`hint`、`sub`、`chip`、`legend`，表格直接用 `<table>`。
